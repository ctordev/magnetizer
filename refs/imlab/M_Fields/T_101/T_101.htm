Аналоговый тесламетр с датчиком Холла типа
ПХЭ для измерения индукции магнитного поля

Назначение

Аналоговый тесламетр предназначен для оперативного измерения и контроля величины индукции постоянного или переменного низкочастотного магнитного поля с помощью датчика Холла типа ПХЭ606118В [1]. Он может использоваться при измерении характеристик магнитных материалов, при разработке и ремонте магнитных систем и устройств с постоянными магнитами, для построения различных измерительных установок и комплексов [2]. При использовании внешнего прибора может применяться для контроля величины амплитуды магнитной индукции в установках импульсного намагничивания и размагничивания [3]. Отличается простотой конструкции, эксплуатации и ремонта.

Технические данные:

  • диапазон измеряемых значений величины индукции магнитного поля 0 ... 2000 мТл разбит на шесть поддиапазонов: 0 ... 50, 0 ... 100, 0 ... 200, 0 ... 500, 0 ... 1000, 0 ... 2000 мТл; имеется знак направления поля и выход для подключения внешнего прибора
  • погрешность измерения не более 4 % при нахождении стрелки прибора во второй половине шкалы
  • диапазон рабочих частот по индукции 0 ... 150 Гц; для переменных магнитных полей измеряется среднее значение модуля индукции
  • в приборе может использоваться датчик С- или М- типа
  • питающая сеть однофазная напряжением 220 + 10 В
  • частота питающей сети 50 + 1 Гц
  • потребляемая мощность не более 25 В ∙ А
  • прибор имеет естественное воздушное охлаждение, готов к работе сразу после включения, время непрерывной работы не ограничено
  • габаритные размеры не более 180 х 200 х 100 мм3 (без элементов управления и подключения)
  • масса не более 1 кг

Устройство тесламетра

Блок-схема аналогового тесламетра с датчиком Холла типа ПХЭ приведена на рис. 1.

Рис. 1. Блок-схема тесламетра.

Блок питания вырабатывает необходимое для питания узлов прибора напряжение. Источник тока служит для стабилизации тока питания датчика Холла (100 мА). Выходное напряжение с датчика Холла подается на усилитель, к выходу которого подключен стрелочный индикатор. Коэффициент усиления и, соответственно, диапазон устанавливается с помощью ручного переключателя. Выходные контакты датчика Холла соединены также напрямую с разъемом, к которому может быть подключен внешний прибор (милливольтметр, осциллограф). С его помощью можно измерять напряжение и контролировать форму сигнала непосредственно на выходе датчика Холла.

Словарь терминов:

  • Датчик Холла (преобразователь Холла) - устройство для получения зависящего от магнитной индукции электрического сигнала, принцип работы которого основан на эффекте Холла.
  • Источник тока - устройство для получения тока постоянной величины в нагрузке переменного сопротивления.
  • Магнитная индукция - вектор, численно равный пределу отношения силы, действующей со стороны магнитного поля на элемент проводника с электрическим током, к произведению тока и длины элемента проводника, если длина этого элемента стремится к нулю, а элемент так расположен в поле, что этот предел имеет наибольшее значение, и направленный перпендикулярно к направлению элемента проводника и к направлению силы, действующей на этот элемент со стороны магнитного поля, причем из его конца вращение по кратчайшему расстоянию от направления силы к направлению тока в элементе проводника должно быть видно происходящим против часовой стрелки.
  • Магнитное поле - разновидность электромагнитного поля, создаваемая движущимися электрическими зарядами или токами и оказывающая силовое воздействие на движущиеся электрические заряды или токи.
  • Тесламетр (гауссметр) - прибор для измерения магнитной индукции.
  • Эффект Холла - возникновение поперечного электрического поля и разности потенциалов в проводнике или полупроводнике, по которому проходит электрический ток, при помещении его в магнитное поле, перпендикулярное направлению тока.
