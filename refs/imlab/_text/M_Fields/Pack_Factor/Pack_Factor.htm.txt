Расчет фактора упаковки
при намотке соленоидов
Фактор упаковки - отношение суммарной площади проводников в
поперечном сечении соленоида без учета изоляции к площади поперечного сечения
соленоида.
Обозначения:
Lambda - фактор упаковки
D - диаметр круглого провода без изоляции
Di - диаметр круглого провода в изоляции
S - площадь поперечного сечения провода или шины без изоляции
Si - площадь поперечного сечения провода или шины в изоляции
h - толщина слоя изоляции
1. Намотка шиной прямоугольного сечения виток к витку
⚠ рисунок PF_01.jpg в локальную копию не скачан — открыть на сайте
Lambda = S/Si
Например, для шины S = 5 х 2 мм 2 (по меди) с
толщиной изоляции h = 0.15 мм:
S = 5 ∙ 2 = 10 мм 2
Si = (5 + 2 ∙
0.15) ∙ (2 + 2
∙ 0.15) = 12.19 мм 2
Lambda = S/Si = 10/12.19 ~ 0.82
2. Намотка круглым проводом виток к витку с послойной
укладкой
⚠ рисунок PF_02.jpg в локальную копию не скачан — открыть на сайте
Lambda = ( p D 2 /4) : Di 2
Например, для провода диаметром D = 1.3 мм (по меди) с
толщиной изоляции h = 0.05 мм (диаметр провода в изоляции D i = 1.4
мм):
Lambda ~ (3.14 ∙ 1.3 2
/4) : 1.4 2
~ 0.68
3. Намотка круглым проводом виток к витку с сотовой
укладкой

Lambda = ( p D 2 /4) : (1.5Di 2 tg30 0 )
Например, для провода диаметром D = 1.3 мм (по меди) с
толщиной изоляции h = 0.05 мм (диаметр провода в изоляции D i = 1.4
мм):
Lambda ~ (3.14 ∙ 1.3 2
/4) : (1.5
∙
1.4 2 * 0.58) ~ 0.78
4. Намотка круглым проводом внавал
⚠ рисунок PF_04.jpg в локальную копию не скачан — открыть на сайте
Для случая намотки внавал максимально достижимое значение
фактора упаковки получаем, когда центры ближайших друг к другу четырех проводов
в трех соседних слоях расположены в вершинах квадрата:
Lambda = ( p D 2 /4) : Di 2
Например, для провода диаметром D = 1.3 мм (по меди) с
толщиной изоляции h = 0.05 мм (диаметр провода в изоляции D i = 1.4
мм):
Lambda ~ (3.14 ∙ 1.3 2
/4) : 1.4 2
~ 0.68
В действительности из-за конечных размеров соленоида,
использования прокладок между слоями, недостаточного натяжения провода, а также
образования дополнительных промежутков между соседними витками, значение фактора
упаковки во всех случаях будет меньше расчетного.

Словарь
терминов:
Катушка индуктивности - электрический контур
(цепь), специально предназначенный для создания собственного магнитного поля
за счет протекающего по контуру тока.
Соленоид (от греч. solen - трубка и
eidos - вид) – осесимметричная катушка индуктивности.
Фактор упаковки (коэффициент заполнения)
- отношение объема проводника к объему обмотки; при равномерной намотке
равен отношению суммарной площади проводников в поперечном сечении обмотки
(без учета изоляции) к площади поперечного сечения обмотки.
