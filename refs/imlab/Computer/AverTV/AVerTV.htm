Установка TV-тюнера AVerTV 203 на компьютер с ОС Windows XP

При установке платы тюнера AVerTV 203 в разъем PCI платы GA-8IR533 (P4 Titan DDR Motherboard) возникла проблема установки драйверов для ОС Windows XP (сборка 2600). Компьютер после каждого включения и загрузки ОС обнаруживал новое устройство и предлагал установить для него драйвера. Однако при установке драйверов возникала ошибка, и установка прерывалась. Попытки устанавливать драйвера вручную, а также замена драйверов на другие ни к чему не привели. Диспетчер устройств интерпретировал тюнер как два неизвестных устройства. Установить программное обеспечение AVerMedia также не удавалось, хотя прием TV с помощью программ, имеющих собственные драйвера, был возможен.

Проблема была решена следующим способом:
При подключенной плате тюнера была произведена переустановка ОС Windows XP "поверх" существующей (режим обновления ОС). Во время этой процедуры был сделан запрос на установку драйверов тюнера. Установка драйверов была сделана с компакт-диска и прошла благополучно. После завершения переустановки ОС "неизвестные устройства" были удалены вручную. Программное обеспечение AVerMedia после этого также удалось установить без проблем.

Словарь терминов:

  • Драйвер - программа, обеспечивающая функционирование комплектующего устройства в составе компьютера.
  • Операционная система (англ. operating system) - базовый набор программ, обеспечивающий работу компьютера и его взаимодействие с пользователем.
