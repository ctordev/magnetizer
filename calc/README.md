## Расчётная точка (актуальная)

Банк **47 мФ** = 10 × EPCOS (TDK) B43560-S9478-M1 4700 мкФ / 400 В, все б/у (5 в наличии, 5 докуп; приёмка
каждой — §3.2 документа). Оснастка **24 витка = 2 слоя × 12**, жила 25 мм² (⌀5.7 мм), шаг 6.5 мм,
**ℓ намотки 78 мм**, bore ⌀100 мм, **L = 45.2 мкГн** (считается из геометрии в `em.js`, не «200 мкГн из воздуха»),
r контура: обмотка 8.5 + шина/тиристор 3.5 + ESR банка 4.0 мΩ (`Rs` в `rlc.js`).
**U = 300 В** — верх, который держит зарядка (T1 255 В с отводом от середины, режимы «255 В» / «127 В», см. ниже), тиристор **Т253-1250-16**, VD6 = **2× ВЛ200**.

| | 300 В | 320 В | 350 В |
|---|---|---|---|
| Энергия / заряд | 2.12 кДж / 14.1 Кл | 2.41 / 15.0 | 2.88 / 16.5 |
| I<sub>pk</sub> · N·I | 6.79 кА · 163 кА·виток | 7.25 · 174 | 7.93 · 190 |
| Поле в кольце ⌀80×16 без ярма | 1.38 МА/м = 38% насыщения (η = 0.135) | 1.47 = 41% | 1.61 = 45% |
| То же с ярмом L×2 / ×3 / ×5 | 126/108/87 кА·виток → 7.8/6.6/5.4 МА/м в изделии | VD6 24–31% на диод | 33–42% |
| T/2 · фронт · τ хвоста · di/dt | 4.6 мс · 2.0 мс · 2.8 мс · 6.5 А/мкс | то же (6.9 / 7.5 А/мкс) | то же |
| Коммутация VT1 | 4.34 мс (диод открылся 2.58 мс) | 4.34 | 4.35 |
| VT1: Itsm / i²t / di/dt / Дж | 24% / 2.0% / 3.2% / 29 | 26% / 2.3% / 3.4% / 32 | 28% / 2.7% / 3.8% / 37 |
| VD6 i²t → 1 диод (2× / 3× ВЛ200) | 61 кА²с → 17% / 11% | 70 → 19% / 13% | 84 → 23% / 16% |
| Ток на банку (однотипный банк, ровно ÷10) | 679 А | 725 | 793 |
| Нагрев обмотки | 1.5 °C | 1.8 | 2.1 |
| Заряд (T1 255 В, 2 лампы 100 Вт = 242 Ом) | 57 с | 80 с | 262 с — на практике не берётся |

Без VD6: коммутация 4.74 мс, банк уходит в **−127 В** (0.38 кДж обратной полярности), экспозиция поля 482 против 837 А·виток·с (×1.7).
Выброс при принудительном срезе 6.8 кА: 1.04 кДж в L1 → в 100 нФ паразитной ёмкости это 144 кВ.
Заряд точной моделью (по полупериодам, `src/charge3.js`), обмотка 255 В, до 300 В: 1 лампа 100 Вт (484 Ом) —
113 с; **2 лампы параллельно (242 Ом) — 57 с, 265 ВА, T1 400 ВА с запасом**; 3 лампы — 38 с (398 ВА, впритык);
4 лампы — 28 с (530 ВА, нужен T1 630 ВА); 75 Ом — 18 с (855 ВА). Столбцы «до 320/350 В» в таблице выше показаны
затем, чтобы было видно: выше 300 В зарядка уже не тянет по времени, а не по «мощности регулятора».
Защитных полупроводников по постоянному току в конструкции нет (crowbar `US2`+`VT2`+`R5` и быстрый aR `FU3` убраны).
Что даёт `rlc()` из `charge.js` при КЗ в оснастке (47 мФ / 300 В, R контура = шины+тиристор 3.5 + ESR банка 4.0 мΩ) по индуктивности петли: 2 мкГн →
19.2 кА / 189 кА²с; 5 → 17.0 кА / 245; 10 → 14.0 кА / 262; 20 мкГн → 11.1 кА / 236. VT1 (Т253-1250: 28 кА, 3920 кА²с)
держит (69…40% Itsm), и банки держат: в однотипном банке деление ровно I/n, при 17 кА это 1695 А на банку
(×2.5 к рабочему выстрелу) — винтовые клеммы, нагрев доли градуса (`rlc.js: split()`). Авария
моста: 435 А, 6.5 кА²с, 71 мс — для KBPC5010 смерть; прервать нечем, спасает только отпущенная `SB1`.

**Лимит режима — больше не банки** (B43560 — серия charge-and-discharge, 679 А на банку для неё штатный режим);
лимитируют окно заряда 60 с и запас по КЗ, и они с запасом. Варианты смягчения — 36 витков (2×18, 521 А на банку),
3 слоя × 8, или работа при 250–280 В (`src/variants.js`).

## Оснастки под готовые динамики (`coils/`)

Отдельная ветка: намагничиваем **собранные головки** 10ГД‑34 (феррит М25РА170, К85×35×15) и 10ГД‑30Е
(керновый альнико ЮНДК‑24). Их собственные фланцы и керн уже работают ярмом, поэтому нужно 25…26 кА·витков,
а не сотни — и режим берём мягкий (120…180 В). Новые формулы не заводятся: L и поле из `em.js`, режим из `rlc.js`.

Затем заменить SVG в `magnetizer.html` по `aria-label` — встраивается **frag-файл** (тело без шапки:
классы `.lbl`/`.lblb` даёт CSS документа; standalone-`*.svg` со своей шапкой стилей предназначен для
отдельного просмотра, в документ его не класть — так в документ однажды попал чужой `<style>`):

```python
def swap(label, path):          # label — фрагмент aria-label нужного svg
    d = open('magnetizer.html', encoding='utf-8').read()
    i = d.index('aria-label="' + label); s = d.rindex('<svg', 0, i); e = d.index('</svg>', i) + 6
    open('magnetizer.html', 'w', encoding='utf-8').write(d[:s] + open(path, encoding='utf-8').read().strip() + d[e:])
swap('Осциллограмма тока диода VD6 и тиристора', 'calc/out/fig_d2.frag.html')
swap('Осциллограммы разряда с диодом VD6 и без него', 'calc/out/fig_vd6.frag.html')
```

`master.js`, `mag10.js` (вьювер и калькулятор в документе) и `yoke3d.js`.

## Правила оформления

- Схемы — по ГОСТ/ЕСКД: позиционные обозначения, точки соединений, без пересечений проводников, без подписей на проводниках.
- **Цены — только в рублях (₽)**, никогда в гривнах/долларах/евро/у.е. Источник в другой валюте — брать цену у российских продавцов.
- Числа в документе и в скриптах обязаны сходиться: если модель правится, правится и текст (в сносках «прежняя ревизия» старые цифры допустимы и помечены как прежние).
