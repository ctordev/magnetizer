# Копия imlab.narod.ru

Копия **уже снята полностью** (272 страницы, 3145 рисунка, 30 архивов, 91 МБ) и чистая по всем проверкам —
заново обходить сайт смысла нет. Вход: `refs/imlab/M_Fields/Magn_Equip/Magn_Equip.htm`. Указатель «какая страница
за что отвечает» и разбор — `imlab-magnetizery.html` §1–§2.

## Где что лежит

| путь | содержимое |
|---|---|
| `refs/imlab/M_Fields/…` | страницы разделов (индукторы, установки, измерения) |
| `refs/imlab/_text/<путь>.htm.txt` | текстовые слепки — **именно их читать**, когда надо процитировать числа |
| `refs/imlab/_notes/fixtures.{json,md}` | паспорта оснасток: зона → B → ток, где публикуется — витки, L, R |
| `refs/imlab/_notes/specs.md` | выжимка «Назначение / Технические данные / Конструкция» |
| `refs/imlab/_notes/integrity.md`, `missing_images.txt` | отчёт проверки и список докачки |
| `refs/imlab/.s/` | локальные ассеты (jquery и т. п.) |

## Снятие и докачка

```bash
SEEDS="https://imlab.narod.ru/M_Fields/xxx/xxx.htm" python3 calc/src/mirror_imlab.py   # новый раздел
FILES=refs/imlab/_notes/missing_images.txt python3 calc/src/mirror_imlab.py             # точечная докачка без обхода ссылок
```

Переменные: `OUT` (по умолчанию `refs/imlab`), `MAX_PAGES`, `IMG=0` (без картинок), `DELAY`, `RETRIES`,
`WAIT_SITE`. При таймаутах скрипт разгоняет паузы 60/120/180 с, а не выходит; `_manifest.tsv` дополняется.
Два параллельных потока дают ≈×2 — narod.ru это выдерживает. Ловушка ожидания: `while pgrep -f "[m]irror_imlab"`
совпадает с собственной командной строкой цепочки — для своих фоновых процессов использовать `wait`.

## Целостность

```bash
python3 calc/src/imlab_check.py            # отчёт; ждём нули по всем пунктам
python3 calc/src/imlab_check.py --fix      # недостающий <img> → обратимая пометка со ссылкой на оригинал
python3 calc/src/imlab_check.py --restore  # вернуть <img>, когда файл докачан
python3 calc/src/imlab_check.py --offline  # убрать чужие сетевые теги (ucoz/счётчики); откат — --online
```

`--offline` уже применён (jquery подтянут из `refs/imlab/.s/`). Остались только протокол-относительные ссылки
ucoz вида `//imlab.narod.ru/…` — офлайн они не грузятся, это не считается дефектом копии.

## Как правильно взять число из копии

1. Найти страницу по указателю или грепом по `refs/imlab/_text` (паспортные строки вида «не менее … Тл при
   амплитуде импульса тока не более … А»). Регулярки должны захватывать десятичные числа: `.` обрывает поиск,
   если шаблон заканчивается на `[^.]{0,120}`.
2. Если число надо пересчитать под нашу оснастку — считать в `calc/src/imlab_compare.js` (он же считает нашу
   оснастку через `em.js`), и только потом править текст в `imlab-magnetizery.html` (§4–§5) и связанные документы.
3. Ссылки в наших документах вести на файл копии (`refs/imlab/M_Fields/<dev>/<dev>.htm`) — `yoke3d.js` проверяет,
   что такие файлы существуют.
4. После расширения копии: `python3 calc/src/imlab_text.py` → `imlab_specs.py` → `imlab_table.py` →
   `node calc/src/imlab_compare.js` → перенос новых строк в §4/§5.

Цен на сайте нет — валютных переводов в этих документах не требуется.
