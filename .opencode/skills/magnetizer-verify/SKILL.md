# Проверка результата

## 1. Скрипты (быстро, из shell)

```bash
python3 calc/src/htmlcheck.py *.html      # наши документы: вложенность тегов, несуществующие локальные src/href,
                                          # повторные id, «сырой» < внутри pre/code → ждём «с замечаниями: 0»
python3 calc/src/imlab_check.py           # копия сайта: недостающие картинки, битые внутренние ссылки,
                                          # обрезанные/пустые страницы → все нули; отчёт refs/imlab/_notes/integrity.md
node calc/src/yoke3d.js                   # геометрия ярма не лезет в обмотку + все ссылки из поля imlab на месте
```

## 2. Браузер (обязательно, это источник правды по рендеру)

Внешний headless chrome и скриншоты через shell — не использовать.

```bash
python3 -m http.server 8811      # в каталоге проекта; file:// не принимается
```

Дальше `tools.browser`: `tabs.open` / `navigate` на `http://127.0.0.1:8811/<doc>?cb=N`.

- `?cb=N` — новый номер после каждой правки: после рестарта сервера вкладка иначе отдаёт 502 или кэшированную копию.
- `browser.screenshot` работает только после `browser.tabs.focus`.
- Что смотреть по документу: `document.title`, число разделов, битые картинки
  (`[...document.images].filter(i => i.complete && i.naturalWidth === 0)`), переполнение таблиц
  (`scrollWidth > clientWidth`), `browser.console` — ошибок быть не должно, 3D-вьювер — что canvas реально
  перерисован (сравнить хэш кадров двух моделей: `getImageData` по alpha не годится, фон непрозрачен везде).
- Ссылки на копию проверять не только по файлам на диске, а прогоном через HTTP — жадная регулярка по `href="..."`
  обязательна (`[^"]+`), иначе будут ложные 404 из-за текста за атрибутом.

## 3. Ловушки Code Mode и evaluate

- Внутри `browser.evaluate` **асинхронные циклы с кликами и `await`** обрываются по таймауту 60 с: клики и чтение
  результата делать **разными** вызовами evaluate.
- После клика по ссылке документ меняется — следующий evaluate на том же табе может упасть с
  «document changed»; сначала `browser.tabs.list()`.
- В `execute` нет `require`/`setTimeout`; для локальных HTTP-проверок подходит `fetch`.

## 4. Что считать «чисто»

`htmlcheck` — 0 замечаний; `imlab_check` — 0/0/0; все локальные ссылки всех документов — 200; консоль каждой
открытой страницы пуста; вьюверы рисуют; битых картинок 0; таблиц без переполнения.
